# Module 1 – Cloud Concepts

## Overview

Cloud computing provides on-demand access to computing resources over the internet.

This module introduces the fundamental concepts that form the foundation of Microsoft Azure.

By completing these labs, I developed an understanding of cloud deployment models, cloud service models, shared responsibility, and the business benefits of cloud computing.

---

## Learning Outcomes

After completing this module I can:

- Explain cloud computing
- Differentiate cloud deployment models
- Explain cloud service models
- Understand Microsoft's Shared Responsibility Model
- Describe cloud characteristics and benefits
