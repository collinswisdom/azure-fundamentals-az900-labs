# ☁️ Microsoft Azure Fundamentals (AZ-900) Hands-On Portfolio

Welcome to my comprehensive **Microsoft Azure Fundamentals (AZ-900)** hands-on engineering portfolio. This repository documents a structured learning path consisting of **12 Modules** and **54 Hands-On Labs**, progressing from core cloud concepts to building a fully secure, governed, and monitored enterprise architecture on Microsoft Azure.

---

## 🎯 Portfolio Objectives

This portfolio goes beyond theoretical exam preparation to demonstrate real-world cloud engineering proficiency:
* 🏗️ **Architecture & Design:** Building multi-tier cloud environments using industry best practices.
* 🛡️ **Security & Governance:** Applying Microsoft Entra ID, Azure RBAC, Zero Trust principles, and Azure Policies.
* 💰 **Cost Optimization:** Leveraging the Azure Pricing Calculator, Azure Advisor, and consumption models.
* 📝 **Technical Documentation:** Creating enterprise-ready architectural diagrams, deployment guides, and post-implementation reviews.
