# Lab Overview

Cloud computing is the on-demand delivery of computing services—including servers, storage, networking, databases, software, analytics, and artificial intelligence—over the internet.

Instead of purchasing and maintaining physical infrastructure, organizations can consume IT resources as services, paying only for what they use.

This lab introduces the core principles of cloud computing and explains why organizations are increasingly adopting cloud platforms such as Microsoft Azure.

# What is Cloud Computing?

Cloud computing is a technology model that enables users to access computing resources over the internet instead of owning and maintaining physical hardware.

These resources include:

- Virtual Machines
- Storage
- Networking
- Databases
- Artificial Intelligence
- Analytics
- Identity Services

Cloud providers such as Microsoft Azure, Amazon Web Services (AWS), and Google Cloud Platform (GCP) operate large-scale data centers that customers access securely over the internet.

---

# How Cloud Computing Works

Instead of purchasing physical servers, organizations rent computing resources from a cloud provider.

The cloud provider is responsible for maintaining the physical infrastructure, while customers consume the services they require.

This allows businesses to rapidly deploy applications without investing heavily in hardware.

---

# Essential Characteristics of Cloud Computing

According to the National Institute of Standards and Technology (NIST), cloud computing has five essential characteristics.

| Characteristic | Description |
|---------------|-------------|
| On-Demand Self-Service | Users can provision resources whenever required. |
| Broad Network Access | Services are accessible over the internet from multiple device types. |
| Resource Pooling | Computing resources are shared among multiple customers. |
| Rapid Elasticity | Resources can scale up or down automatically based on demand. |
| Measured Service | Customers pay only for the resources they consume. |

# Advantages of Cloud Computing

Cloud computing provides several business advantages.

- Reduced capital expenditure
- Faster deployment
- Global availability
- Automatic scalability
- Improved disaster recovery
- High availability
- Flexible pricing models

---

# Real-World Example

A startup launching an e-commerce website can deploy its application on Microsoft Azure instead of purchasing physical servers.

As customer demand grows, Azure automatically scales the infrastructure to handle increased traffic without requiring the company to purchase additional hardware.
