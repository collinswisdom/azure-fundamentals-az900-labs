# Azure Architecture

This section covers key Azure architectural components and how they are organized to build scalable, secure, and highly available cloud solutions.

---

### 🔷 Topics Covered

* **Azure Regions**
* **Availability Zones**
* **Resource Groups**
* **Azure Resource Manager**
* **Azure Subscriptions**

---

### 📦 Overview

Azure provides a global infrastructure designed for high availability, scalability, and reliability.

* **Regions:** Physical locations around the world.
* **Availability Zones:** Physically separate data centers within a region.
* **Resource Groups:** Logical containers for resources.
* **Azure Resource Manager:** Deployment and management service for Azure resources.
* **Subscriptions:** Logical billing and access boundaries.
